# 技术方案文档

这是一个对标 Typora 的跨平台 Markdown 编辑器原型，演示现代极简的视觉风格与 WYSIWYG 所见即所得的编辑体验。

## 核心特性

  • 所见即所得：输入即渲染，光标所在行才显示源码标记
  • 克制动效：高频操作零动效，低频操作短促优雅
  • 内容优先：界面中性安静，色彩花在内容上

## 代码示例

import { useSpring } from 'motion'

// 只动画 transform，GPU 加速
const x = useSpring(0, { stiffness: 100 })
